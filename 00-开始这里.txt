大肥鱼 · 傲娇鲸鱼娘 · 微信群 AI 助手（快速开始）
================================

【三步跑起来】
1. git clone 或下载 ZIP 解压到电脑，建议放 D:\wechat-group-ai
2. 双击 setup.bat，按提示装依赖、登录微信小号、填群名/昵称/API Key
3. 双击 启动助手.bat，打开桌面 APP，它会自动启动接管
4. 在群里发：大肥鱼 你好（不用 @ 也行）
   - 这台机器已设成边用电脑边回；全屏游戏/视频仍会暂停

【必须你自己做的三件事】
- 用 AI 小号登录微信，并进群；群昵称和 BOT_NAMES 一致（当前：大肥鱼）
- 填一个模型 API Key（DeepSeek 最省事）
- 确认微信是 4.1.12+（4.1.15.53 已验证）

【常用】
启动助手.bat    桌面 APP：打开自动接管，关窗自动退出接管
run.bat          命令行正式运行（和 APP 二选一）
run_forever.bat  命令行崩溃自动重启（开机自启用的就是它）
编辑配置.bat     用记事本改 config.py（群、昵称、上下文、暂停策略）
编辑人设.bat     用记事本改 persona.txt
编辑模型.bat     用记事本改 .env（模型名/Key）
check.bat        一键体检，生成 check.log
更新热梗.bat     立刻联网搜集热梗，更新 memes.json
fix-window.bat   微信窗口/UIA 异常时恢复

用了 APP 就在 APP 里改配置；编辑配置.bat / 编辑人设.bat 适合不用 APP 的时候。

【桌面 APP】
打开后默认自动启动接管；顶部有 启动接管 / 退出接管 / 重启接管 / 保存配置。
基础、模型、人设、热梗、表情包、运行都能在 APP 里改，保存后重启接管生效。
关闭窗口 = 退出接管并恢复微信窗口。APP 和 run.bat 不要同时开。

【怎么叫它】
默认 smart 模式：叫「大肥鱼 / 鲸鱼娘 / 蓝鱼 / 鱼鱼 / 小助手 / DS / DeepSeek」都行，不用每次 @；刚聊完接着问“那你觉得呢/为啥/还有呢”，它会当成同一轮继续聊。
人设是傲娇鲸鱼娘：嘴硬心软、爱米饭、偶尔哼一声，但正经问题会好好答。
只有你明确 @ 它时，回复才带 @；叫名字和追问都不 @，更像群友。
回答默认简短：闲聊 1 句，普通问题 2-3 句，复杂问题最多 5 条、300 字。

【图片识别】
多数情况密钥自动可用；图可以在叫它之前或之后发，问“图/截图/界面/报错”类问题会等 2 秒看有没有图。
如果 --doctor 显示未抓取、或图片一直读不出来，再手动抓一次：
1. 先停机器人，让微信窗口能看到
2. 运行：python bot.py --capture-image-key
3. 120 秒内，在微信里点开任意一张图片看大图
4. 看到“图片密钥已抓取并缓存”就好了，重启 run.bat

【评价/打分】
大肥鱼 评价一下这张图 / 点评一下这个方案 / 给这段话打个分
会给“总评 + 优点 + 问题 + 建议”；要分数给 1-10 并说标准；可以损友式吐槽，但不攻击身体缺陷/家人/隐私，不认真给人排名。

【发图/表情包】
仓库不附带表情包图片（第三方图片授权为 personal use，不能随项目分发）。
把自己的图片放进 stickers/，文件名用“标签_xxx.png”，说明见 stickers/README.md；python bot.py --list-stickers 可看每个分类数量。
大肥鱼 发个表情包 / 发个傲娇的表情 / 发个害羞的表情 / 发个卖萌的表情 / 发个御姐的表情 / 发个玩梗的表情 / 来张图；后台发送，不弹窗。
群友发表情包时：正在跟它聊或刚问过它，它会截屏识别并接一句；识别时窗口会短暂恢复约 1 秒截图。

【网络热梗】
面向 20 岁左右，优先 AI 相关：默认每 12 小时抓微博/百度/抖音/B站/头条热榜，外加 B站 AI 梗、AI 黑话、赛博梗和 HN 讨论，提炼后写进 memes.json，回复时自动带进提示词。
想立刻更新：双击 更新热梗.bat；想看看学了什么：python bot.py --show-memes。

【注意】
- 首次启动/首次发送会往 Weixin.dll 内存写一个无障碍字节，并读取本地数据库密钥；这是第三方改动，有微信风控/封号风险，务必用小号
- 同一台电脑的微信一次只能登一个号；机器人要跑，就必须登着 AI 小号
- 新后端支持微信 4.1.12+，不用再降级到 4.1.8
- 运行期间微信窗口会被移到屏幕外，回复不弹窗；停止后自动恢复（Ctrl+C）
- 回复时会短暂借一下键盘焦点（约 0.2 秒）再还给你；期间不要用这个微信号聊天
- 头像/群昵称是微信账号资料，改 persona.txt 不会变；头像在微信「我」里改，群昵称在群设置→我在本群的昵称里改
- 非官方自动化违反微信用户协议，有账号被限制的风险，风险自担
