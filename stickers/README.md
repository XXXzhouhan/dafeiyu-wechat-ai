# 表情包目录

仓库**不附带**任何表情包图片。

本项目的表情包功能需要你自己准备图片，原因如下：

- 原项目使用的 132 张图来自第三方仓库，授权为 personal use，不能随本项目再分发
- 表情包本身可能涉及角色形象、画师作品的版权

## 使用方式

把图片直接放进本目录，文件名格式为 `标签_任意名字.后缀`，例如：

```
开心_01.png
无语_猫猫.gif
害羞_比心.webp
```

- 支持 png / jpg / jpeg / gif / webp
- 标签决定机器人什么时候发这张图，常用标签：`开心`、`无语`、`生气`、`摸鱼`、`问号`、`吃瓜`、`赞`、`搞笑`、`打工人`、`可爱`、`抽象`
- `categories.json` 是「场景 → 标签」的映射，可以按自己的图库修改
- 运行 `python bot.py --list-stickers` 查看各分类数量

## 图片来源与授权

原项目图片的来源与授权记录保存在本地 `CREDITS.md`，该文件不随仓库分发。请只使用你有权使用的图片；因图片版权产生的纠纷与本项目无关。
