# 大肥鱼 · 微信群 AI 助手 (WeChat Group AI Bot)

在 Windows 上跑一个属于你的微信群 AI 成员：用微信小号登录，读取本地数据库的新消息，被叫到、@ 或接着追问时调用 DeepSeek 回复，再用 UIA 把回复发回群里。

不需要 OCR，也不会一直轮询微信界面；回复时微信窗口在屏幕外后台发送，不会弹出来。

> 首次启动/首次发送会往 `Weixin.dll` 内存写一个无障碍字节，并读取本地数据库密钥。这是第三方改动，不是官方接口，有微信风控/封号风险，请务必用小号。

---

## 1. 它怎么工作

- **读**：解密本机微信 4.x 的 SQLCipher 数据库（只读），拿到群消息和发送者
- **想**：调用 DeepSeek（默认 `deepseek-chat`），人设写在 `persona.txt`
- **学**：定时抓微博/百度/抖音/B站/头条热榜，外加 B站 AI 梗和 HN 讨论，提炼适合 20 岁左右、优先 AI 的热梗，回复时注入提示词
- **发**：热激活微信的 Qt 无障碍树，用 UIA 把回复发到目标群
- **省资源**：数据库 1 秒查一次；你在用电脑（10 秒内有键鼠）时完全暂停；全屏游戏/视频也暂停

---

## 2. 环境要求

- Windows 10 / 11 x64
- Python 3.9–3.12（推荐 3.12；3.13 可能装不上 `winsdk`）
- 微信 Windows **4.1.12+**（4.1.15.53 已验证）
- 一个 AI 小号：已登录、已进群，群昵称和配置一致
- DeepSeek API Key（或兼容 OpenAI 接口的其他模型）

> 同一台电脑的微信一次只能登录一个号。机器人要跑，就必须登着 AI 小号。

## 3. 第一次部署

1. `git clone https://github.com/XXXzhouhan/dafeiyu-wechat-ai.git`，或下载 ZIP 解压，建议放 `D:\dafeiyu-wechat-ai`
2. 双击 **`setup.bat`**，按提示完成：
   - 安装 Python 依赖（`wechatauto-replica` 等）
   - 安装/登录微信 4.1.12+
   - 填群名、小号群昵称、模型 API Key
   - 跑一次自检
3. 双击 **`启动助手.bat`** 打开桌面 APP，它会自动启动接管
4. 在群里发 `大肥鱼 你好`（不用 @）
5. 如果之前把“用电脑时暂停”打开了，发完后别动键鼠约 10 秒；当前配置已关掉暂停

第一次发送会热激活微信无障碍树，可能多等一两秒，属于正常现象。

## 4. 日常使用

- **`启动助手.bat`**：打开桌面 APP，自动接管；关掉窗口自动退出接管
- **`run.bat`**：命令行前台运行，控制台看日志，Ctrl+C 退出
- **`run_forever.bat`**：命令行崩溃后 5 秒自动重启（开机自启用的就是它）
- **`编辑配置.bat`**：用记事本打开 `config.py`
- **`编辑人设.bat`**：用记事本打开 `persona.txt`
- **`编辑模型.bat`**：用记事本打开 `.env`（改 Key / 模型名）
- **`check.bat`**：一键体检，生成 `check.log`
- **`fix-window.bat`**：微信窗口异常/找不到时，重新激活 UIA 并恢复窗口

群里不一定要 @：叫它「大肥鱼 / 鲸鱼娘 / 蓝鱼 / 鱼鱼 / 小助手」，或者刚聊完直接追问，它都会接。安装向导默认关闭“用电脑时暂停”，可以边用边聊；全屏游戏/视频仍会暂停。

机器人运行期间，微信主窗口会被移到屏幕外；停止（Ctrl+C）后自动恢复。期间不要用这个微信号聊天，否则会被机器人打断。想看微信就先停机器人，或双击 `fix-window.bat`（下一次回复可能又移走）。

### 4.1 桌面助手 APP

双击 `启动助手.bat`，会打开一个窗口，并默认自动启动接管。

- 顶部：`启动接管` / `退出接管` / `重启接管` / `保存配置`
- 页签：基础、模型、人设、热梗、表情包、运行
- 关闭窗口 = 退出接管，机器人会收到停止信号并恢复微信窗口
- 配置保存在 `config_local.py`、`.env`、`persona.txt`，和手动改文件等价
- 用了 APP 后，群名/昵称/触发方式等以 APP 保存的 `config_local.py` 为准；不要再改 `config.py` 里的同名项，会被覆盖
- 不想打开就自动接管：在「运行」页取消勾选「打开 APP 时自动启动接管」
- 想边用电脑边聊：把「用电脑时暂停」两个开关都关掉
- APP 和 `run.bat` 二选一，不要同时开两个机器人

如果点了启动但状态很快变成「已退出」，看下方运行日志；常见原因是微信没登录、登录的不是 `EXPECTED_ACCOUNT` 指定的小号、群名不一致或 API Key 为空。

## 5. 配置说明

### 5.1 群、昵称、账号

打开 `编辑配置.bat`：

```python
GROUPS = ["测试群"]           # 群名，必须和微信里一字不差
BOT_NAMES = ["大肥鱼"]        # 群里 @ 的名字，可填多个
EXPECTED_ACCOUNT = "测试小号"  # 只允许这个微信昵称当机器人，防主号误跑
```

`EXPECTED_ACCOUNT` 对不上会拒绝启动；如果换了小号，把它改成新的微信昵称。

### 5.2 怎么叫它

```python
TRIGGER_MODE = "smart"       # at=只认@ / at_or_keyword=认名字和关键词 / smart=再加追问
KEYWORDS = ["小助手", "机器人", "肥鱼", "鱼鱼", "蓝鱼", "鲸鱼娘", "DS", "DEEPSEEK"]
TRIGGER_BY_NAME = True       # 叫「大肥鱼」不带 @ 也回
FOLLOW_UP_SECONDS = 120      # 刚聊完，同一个人 120 秒内继续说话不用再叫
FOLLOW_UP_TURNS = 3          # 每轮回完会续上，120 秒内可以一直聊
```

`smart` 模式下：

- `@大肥鱼 这个报错怎么修`：正常回，并带 `@你`
- `大肥鱼在吗` / `鲸鱼娘 今天吃什么` / `蓝鱼 帮我看下`：不用 @，直接回，不 @ 你
- `DS 帮我看下` / `ds 多少钱` / `DeepSeek 在吗`：DS、ds、DEEPSEEK、deepseek 大小写都认
- 但 `ds真的好便宜`、`我觉得ds很好用` 这种讨论 DeepSeek 本身的话不会触发，避免在 AI 群里乱接话
- 刚问完，接着随便说一句（不用 @/叫名字）都会当成同一轮聊天
- 刚聊完又 @/叫名字但没带问题：不会回「有什么问题」，会安静等你继续
- 群里别人插话不会触发；超过 120 秒没说话，才需要重新叫它

`ds` 在 AI 群里出现频率很高，嫌它太吵就把 `DS` 从 `KEYWORDS` 里删掉。

想回到只在被 @ 时回复，把 `TRIGGER_MODE` 改成 `"at"`。

### 5.3 模型和 Key

`.env`（由 `configure.py` 生成，也可以直接改）：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=你的key
LLM_MODEL=deepseek-chat
```

- `deepseek-chat`：中间档，默认；速度快、输出 token 少，日常群聊够用
- `deepseek-flash`：带推理，简单问题也可能想很久
- `deepseek-reasoner`：推理中间档，更慢
- `deepseek-v4-pro`：最强，但也最慢、最贵
- 换智谱/通义/Kimi：改 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY` 即可

> `deepseek-chat` 不在当前 `/models` 列表里（列表只写 flash / v4-pro），但接口能正常调用，属于兼容别名；哪天失效了就换回 flash 或 v4-pro。

图片识别单独用 `VISION_MODEL`，默认 `deepseek-flash`（`deepseek-v4-pro` 实测不读图）。它和文本共用同一个 Key，不用另配。

### 5.4 上下文和回复

```python
CONTEXT_SIZE = 60          # 带最近 60 条消息做上下文
MAX_REPLY_CHARS = 300      # 单条回复最多字数
MIN_INTERVAL = 5.0         # 同群两次回复最小间隔（秒）
IMAGE_FOLLOW_SECONDS = 60  # 先叫它再发图，多少秒内算同一次提问
```

默认按“简洁”回答：闲聊 1 句，普通问题 2-3 句，复杂问题最多 5 条、300 字。上下文越大越懂前因后果，但 token 费用和延迟也会涨；数据库读取本身很便宜，瓶颈在模型。

### 5.5 别打扰你

```python
PAUSE_READ_WHEN_ACTIVE = True   # 你在用电脑时连消息都不读
ACTIVE_IDLE_SECONDS = 10.0      # 空闲超过 10 秒才处理
PAUSE_WHEN_FULLSCREEN = True    # 全屏游戏/视频时暂停
LOW_PRIORITY = True             # 机器人进程降优先级
HIDE_WECHAT_WINDOW = True       # 窗口移到屏幕外，回复不弹窗
```

想边用电脑边让它回消息，把 `PAUSE_WHEN_ACTIVE` 和 `PAUSE_READ_WHEN_ACTIVE` 都改成 `False`（安装向导默认就是关的）。回复仍然在后台发送，不会弹出聊天框，只是会短暂借一下输入焦点（约 0.2 秒）再还给你；全屏游戏/视频仍会暂停。怕被打扰就把这两项改回 `True`。

### 5.6 图片识别

微信图片是加密的，但密钥多数情况能自动派生；机器人遇到图片会自己下载、解密、看图。只有 `--doctor` 显示未抓取、或者图片一直读不出来时，才手动抓一次：

1. 停掉机器人，确认微信窗口能看到
2. 双击 `fix-window.bat`（如果窗口在屏幕外）
3. 在终端运行 `python bot.py --capture-image-key`
4. 命令会等 120 秒：这期间在微信里打开任意一张图片，点开看大图
5. 看到「图片密钥已抓取并缓存」就好了，重启 `run.bat`

用法：

- 图可以在 `@大肥鱼` **之前**或**之后**发；问「图 / 截图 / 界面 / 报错」类问题时，机器人会等 2 秒看有没有图
- 也可以先发图，再 `@大肥鱼 这个怎么弄`
- 同一张图 60 秒内有效；只支持本机已经收到过的图片
- `python bot.py --test-vision`：用生成的测试图检查视觉模型
- 想让图片用别的模型：改 `config.py` 的 `VISION_MODEL`（`deepseek-flash` 实测能看图）

### 5.7 评价 / 打分

在群里叫它说：

- `大肥鱼 评价一下这张图`（图在前后都行）
- `大肥鱼 点评一下这个方案：……`
- `大肥鱼 给这段话打个分`

它会先给明确倾向/分数，再按「优点 → 问题 → 建议」说；不为了礼貌硬夸，也不空骂。要分数就给 1-10 分，并说明按什么标准。

可以像损友一样吐槽照片、穿搭、表情、方案、发言；但不攻击身体缺陷/疾病、不辱骂家人、不泄露隐私、不搞地域/性别/政治攻击，也不认真给人打分排名。对方明显不舒服就收。

被问「我帅不帅」会打趣点评照片，但不会硬夸「太帅了」；被问看法/预测（比如比赛谁能赢）会给明确判断和理由，不用「看情况」糊弄。

### 5.8 发图 / 表情包

把图片放进 `stickers/`，文件名用 `标签_任意名字.后缀`，例如 `开心_1.png`、`无语_猫猫.gif`。

分类：`开心`、`无语`、`生气`、`摸鱼`、`问号`、`吃瓜`、`赞`、`搞笑`、`打工人`、`可爱`、`抽象`；细标签还有嫌弃、拒绝、求饶、震惊、加班、花痴、害羞、猫爪、求打赏、干饭、躺平、比心、飘了等。支持 png / jpg / gif / webp。

运行 `python bot.py --list-stickers` 可以看每个分类下有多少张。

在群里叫它说：

- `大肥鱼 发个表情包`
- `大肥鱼 发个傲娇的表情`
- `大肥鱼 发个害羞的表情`
- `大肥鱼 发个卖萌的表情`
- `大肥鱼 发个御姐的表情`
- `大肥鱼 发个玩梗的表情`
- `大肥鱼 发个开心的表情`
- `大肥鱼 发个打工人的表情`
- `大肥鱼 发个可爱的表情`
- `大肥鱼 发个抽象的表情`
- `大肥鱼 来张图`
- 也可以直接说 `发个表情包` / `来个表情`，不用叫名字

它现在更像群友：普通闲聊回复完，有 15% 概率顺手补一张表情；正经报错/配置类长回答不会补。模型也会偶尔自己带 `[表情:开心]`。发送走后台，图片不会弹窗；`stickers/` 空着时它会说“没表情包，放几张”。

```python
STICKER_CHANCE = 0.15          # 闲聊后补表情的概率
STICKER_MAX_REPLY_CHARS = 120  # 超过这个字数就不补，避免正经回答后跟图
```

群友发表情包时也会认：如果正在跟它聊、或者刚问过它，它会截下表情包交给视觉模型识别，再像群友一样接一句；没在聊时也有 60% 概率接一张，嫌吵就把概率改成 0。

```python
REACT_TO_STICKERS = True       # 是否识别群友发的表情包
STICKER_REACT_CHANCE = 0.6     # 没在聊时随机接表情包的概率，0=不接
STICKER_MIN_INTERVAL = 3.0     # 两次表情包识别的最小间隔
```

识别表情包时会把微信窗口短暂恢复约 1 秒截图，完成后再移走；窗口可能会闪一下，属于正常现象。需要视觉模型可用（默认 `deepseek-flash`）。

仓库不附带表情包图片：原项目使用的图片来自第三方，授权仅限 personal use，不能随本项目再分发。请把自己有权使用的图片放进 `stickers/`，详见 `stickers/README.md`；没有图片时机器人会提示“没表情包，放几张”，其他功能不受影响。

### 5.9 人设

默认人设是「傲娇鲸鱼娘」：蓝白配色、鲸鱼尾鳍、爱吃米饭，嘴硬心软，回复短一点。打开 `编辑人设.bat`，改 `persona.txt`：

- `#` 开头的行会被忽略
- 其余文字会**追加**到系统提示词
- 不要写花括号 `{}`（会被当成格式化占位符）
- 改完重启 bot 生效；`python bot.py --show-prompt` 查看最终提示词

### 5.10 网络热梗语料

机器人会定时联网看热榜，还会搜 B站上的 AI 热梗、AI 黑话、赛博梗、AI 翻车，以及 Hacker News 的 AI 讨论；从中挑出适合 20 岁左右年轻人的说法，优先收 AI 相关，存到 `memes.json`。回复时带最近 18 条进提示词，AI 梗最多占 70%。只丰富说话方式，不改变人设。

- 默认每 12 小时更新一次；启动时如果语料过期，会在后台自动更新，不耽误回消息
- 不想联网：`MEME_ENABLE = False`
- 每次带多少条进提示词：`MEME_PROMPT_LIMIT = 18`
- 提示词里 AI 梗占比：`MEME_AI_RATIO = 0.7`
- 超过多少天没再出现就淘汰：`MEME_TTL_DAYS = 30`
- 每次更新会花一次小模型请求；觉得费 token 就把 `MEME_REFRESH_HOURS` 调大

手动更新 / 查看：

```powershell
python bot.py --update-memes   # 立刻联网搜集，写入 memes.json
python bot.py --show-memes     # 看现在库里有哪些梗
```

也可以双击 `更新热梗.bat`。`memes.json` 删了会自动重建；里面的 `meaning` / `usage` 可以直接手改，改完重启生效。

热榜和 B站 AI 内容只提供线索，模型负责提炼；当天没有合适的热梗就少收或不收，不会硬编。

## 6. 常用命令

```powershell
python bot.py --doctor             # 体检：账号、数据库、群、UIA、图片密钥
python bot.py --dry-run            # 只读消息、只打印回复，不发送
python bot.py --test-llm           # 只测文本模型
python bot.py --test-vision        # 用生成的测试图测视觉模型
python bot.py --capture-image-key  # 抓图片密钥（先点开一张图）
python bot.py --list-sessions      # 列出数据库会话
python bot.py --show-prompt        # 打印最终系统提示词（含人设和热梗）
python bot.py --update-memes       # 联网搜集热梗，更新 memes.json
python bot.py --show-memes         # 查看已收集的热梗语料
python bot.py --fix-window         # 激活 UIA 并恢复微信窗口
```

日志在 `bot.log`（控制台也会打印）。

## 8. 常见问题

**一定要 @ 吗？**
不用。默认 `TRIGGER_MODE = "smart"`：叫「大肥鱼 / 鲸鱼娘 / 蓝鱼 / 鱼鱼 / 小助手」，或者刚聊完接着追问，都能触发。只有你明确 @ 它时，回复才会带 @。

**聊到一半不 @ 会接吗？**
会。机器人回完后 120 秒内，同一个人随便说一句都会接，@/叫名字不是必须。你 @ 它但没带问题，它不会回「有什么问题」，会等你把话说完；纯「嗯/好的/谢谢」不接。

**叫了没反应？**
先看 APP 状态是不是「接管中」；再看「运行」页的暂停开关有没有打开；再确认群名、`BOT_NAMES`、`KEYWORDS`、账号 `EXPECTED_ACCOUNT` 是否一致。追问只看“同一个人 + 机器人刚回完 + 120 秒内”，每轮回复会续上；纯「嗯/好的/谢谢」不接。

**APP 和 run.bat 能一起开吗？**
不要。两个机器人会抢同一个微信窗口。用 APP 就关掉 `run.bat`；用 `run.bat` 就别开 APP 接管。程序会用 `bot.pid` 防止重复启动；看到「已经有一个机器人在运行」时，先停掉旧的那个。

**提示「不是机器人小号」？**
当前登录的微信不是 `EXPECTED_ACCOUNT` 指定的账号。切回小号，或改成当前账号的微信昵称。

**UIA 控件树不可用 / 发送失败？**
先跑 `--doctor`。确认微信 4.1.12+、已登录、窗口没被锁屏；不行就双击 `fix-window.bat`。如果微信刚升级，gate RVA 可能变了，等 `wechatauto-replica` 更新或临时重启微信再试。

**模型报 401 / 429 / 超时？**
用 `--test-llm` 单独排查：401 是 Key 不对，429 是限流，超时可以把 `LLM_TIMEOUT` 调大或换 `deepseek-flash`。

**回答还是敷衍 / 不解决问题？**
现在用的是“先结论、再给必要步骤”的提示词，默认 `deepseek-chat`。还嫌浅就把 `.env` 的 `LLM_MODEL` 换成 `deepseek-v4-pro`（更慢/更贵），或者把 `MAX_REPLY_CHARS` 调大。

**回答太长 / 想更短？**
默认已经走简洁模式：闲聊 1 句，普通问题 2-3 句，复杂问题最多 5 条、300 字。想更短就改 `persona.txt` 里的说话方式，或把 `MAX_REPLY_CHARS` 调到 200；想更详细就把这两个地方一起放宽。

**发图没反应 / 图片没读出来？**
图可以在叫它前后发，别隔太久（60 秒内）。如果 `--doctor` 显示图片密钥未抓取，按 5.6 抓一次。只支持本机微信已经收到过的图片；太旧或被清理的图会下载失败。

**能评价 / 打分吗？**
可以。叫它说「评价一下这张图」「锐评一下这个方案」「给这段话打个分」；它会先给明确倾向/分数，再按「优点 → 问题 → 建议」说，要分数给 1-10 并说明标准。可以损友式吐槽，但不攻击身体缺陷/家人/隐私，也不认真给人排名。

**能发图 / 表情包吗？**
可以。把图片放 `stickers/`，文件名 `标签_xxx.png`；叫它说「发个表情包」「发个开心的表情」「来张图」。普通闲聊回完也有 15% 概率顺手补一张，正经长回答不补。发送走后台，不弹窗。

**能看懂群友发的表情包吗？**
能。正在跟它聊、或者刚问过它时，它会截下表情包交给视觉模型识别，再像群友一样接一句；没在聊时也有 60% 概率接；如果上文在问这个表情，它会解释是什么梗。识别时微信窗口会短暂恢复约 1 秒截图，可能会闪一下。

**它说话会带热梗吗？**
会。默认每 12 小时抓一次热榜和 B站 AI 梗，按 20 岁左右的口味提炼，优先收 AI 相关，写进 `memes.json`，回复时带最近 18 条进提示词（AI 梗最多 70%）。想立刻更新就双击 `更新热梗.bat`，或用 `python bot.py --show-memes` 看现在学了什么。它只会在合适时自然用，不会硬塞。

**会不会封号？**
任何非官方自动化都有风险。只用小号、只在自己的群、只响应叫它/关键词、控制频率；出现“操作频繁/账号风险”提示就停几天。

**回复会 @ 人吗？**
只有你明确 @ 它时，回复才带 `@昵称`；叫名字、关键词、追问都不带。带的是纯文本，不是微信里可点击的蓝色 mention。

**回复时会弹出聊天框吗？**
不会。窗口会移到所有显示器之外，回复在后台发送；只会短暂借一下键盘焦点（约 0.2 秒）再还回去。把 `HIDE_WECHAT_WINDOW` 改成 `False` 就改回前台发送。

**群友看到的头像/名字没变？**
`persona.txt` 只改说话风格，不改微信资料。头像在微信「我」里改；群里显示的是**群昵称**，在群设置 → 我在本群的昵称里改。改完重进群或重启微信刷新缓存。如果连账号昵称也改了，记得把 `config.py` 的 `EXPECTED_ACCOUNT` 同步成新昵称。
